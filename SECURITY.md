# Security Policy

## Supported versions

Only the latest release receives fixes.

| Version | Supported |
| ------- | --------- |
| 2.2.x   | ✅ |
| < 2.2   | ❌ |

## Reporting a vulnerability

Please do not open a public issue for security problems, such as a way for a submission to run code outside its sandbox, read data it should not, or access the cluster or CI credentials.

Email arel.encin@mail.utoronto.ca instead. We aim to reply within one week and will keep you updated until the issue is fixed or declined. Accepted reports are credited in the release notes unless you prefer otherwise.

Submitted models run on our cluster through CI, so reports about the submission pipeline are especially welcome.
